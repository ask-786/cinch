About Cinch

Cinch is a browser front end for FFmpeg, compiled to WebAssembly. When you pick a file, the file is handed to a worker thread running inside this tab. Nothing is sent over the network — there is no server that could receive it.

What that means in practice

  • Speed depends on your own machine, not on a queue somewhere.
  • Very large files are limited by how much memory the tab can use, not by an upload cap.
  • Once the page is loaded it works offline.
